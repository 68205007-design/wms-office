# ติดตั้ง Backend บน Google Apps Script (ฟรี ใช้ได้ตลอด)

ข้อมูลทั้งหมดเก็บใน Google Sheets ของคุณเอง ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องใส่บัตรเครดิต

## ขั้นตอน (ประมาณ 5 นาที ทำครั้งเดียว)

1. เปิด <https://sheets.new> (สร้าง Google Sheet ใหม่) ตั้งชื่อเช่น `WMS ฐานข้อมูล`
2. เมนู **ส่วนขยาย → Apps Script**
3. เปิด <https://raw.githubusercontent.com/68205007-design/wms-office/main/apps-script/Code.gs>
   กด **Ctrl+A** แล้ว **Ctrl+C** เพื่อคัดลอกโค้ดทั้งหมด
4. กลับไปหน้า Apps Script ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววาง (**Ctrl+V**) → กด 💾 บันทึก
5. ที่แถบด้านบน เลือกฟังก์ชัน **setup** แล้วกด **▶ เรียกใช้**
   - กด **ตรวจสอบสิทธิ์** → เลือกบัญชี Google → **ขั้นสูง** → **ไปที่ ... (ไม่ปลอดภัย)** → **อนุญาต**
     (เป็นสคริปต์ของคุณเอง Google จึงเตือนว่ายังไม่ผ่านการตรวจสอบ)
   - ดู **บันทึกการดำเนินการ** ด้านล่าง จะมี **อีเมลและรหัสผ่านผู้ดูแลระบบ** → จดไว้
6. ปุ่ม **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่**
   - ⚙ ประเภท: **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
   - กด **ทำให้ใช้งานได้** → คัดลอก **URL ของเว็บแอป** (ลงท้าย `/exec`)
7. ใส่ URL ใน GitHub: repo → **Settings → Secrets and variables → Actions → Variables → New repository variable**
   ชื่อ `GAS_URL` ค่า = URL จากข้อ 6 → แล้วรัน workflow **Deploy WMS to GitHub Pages** ใหม่
   (หรือส่ง URL ให้ผู้ดูแลโปรเจกต์ตั้งค่าให้)

## หมายเหตุ

- **อัปเดตโค้ด:** วางโค้ดใหม่ → บันทึก → การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✏ แก้ไข → เวอร์ชัน: **ใหม่** → ทำให้ใช้งานได้ (URL เดิม)
- **ลืมรหัส admin:** เลือกฟังก์ชัน `resetAdminPassword` → เรียกใช้ → ดูรหัสใหม่ในบันทึก
- รูปสินค้าเก็บใน Google Drive โฟลเดอร์ `WMS - รูปสินค้า` (แชร์แบบดูได้ผ่านลิงก์)
- ส่งออก Excel / PDF (ภาษาไทยได้) / CSV ผ่าน Google Sheets
- ทุกคำขอที่แก้ไขข้อมูลทำงานทีละคำขอ (LockService) ป้องกันการตัดสต็อกซ้ำ
- โควตาฟรีของ Google เพียงพอสำหรับสำนักงานทั่วไป แต่ละคำขอใช้เวลาประมาณ 1–3 วินาที
